# Pipeline agent workflow

The user operates this project through an agent host. To execute the full pipeline, use native subagents for the generated semantic review assignments when available. Do not spawn unrelated implementation agents. Use the user's existing Python environment with `-B`; never install dependencies, download models, or change the environment. The original workstation uses the conda environment named MSAP; resolve its existing interpreter without creating another environment.

Run `pipeline.py next --run RUN` and perform the indicated stage, repeating until complete. When it requests `agent_review`, dispatch each missing job to a fresh-context native agent, at most three concurrently. A review worker may read only its assigned job JSON, which contains the prompt, complete source context, numbered options, input hashes and output_path. It must read the complete file, including portions truncated by tool output. It must perform real semantic judgment; code may copy IDs or serialize JSON but must not replace judgment with keyword rules. Write exactly the prescribed response to output_path, then return the job_id. Do not delegate further or browse. The coordinator validates responses before advancing dependent stages. Persist completed valid jobs and retry only failed/missing assignments.

Boundary: return keep/drop/need_more plus reason for every group. Keep all passing passages. Paragraph: each group contains exactly one candidate, not the full parent passage or every option. Return keep/drop with a specific reason. The coordinator runs paragraph-jobs again only for unresolved parents; never review additional candidates after a usable first hit. Sentence: review only this round's marked IDs against the full natural-paragraph background. The coordinator runs sentence-jobs again if fewer than 200 unique usable sentences passed; stop at the quota or pool exhaustion. Finish each dispatched round before creating its dependent round, and do not mix speculative future rounds. Use next to determine the next action. Never invent approvals to make stage counts complete.

Run directories contain original books and private review material. They are excluded from Git by default. Do not publish them or credentials when updating this code repository. Existing v1/v2 reviews cannot be silently reused under the changed v2.1 review inputs and policy; use a new run. No tasks or original-text generation are part of this pipeline.
